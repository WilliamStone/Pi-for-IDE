# pi-code — Pi Web+ / pi for IDE

[English](./README.md) | [中文](./README.zh-CN.md) | [日本語](./README.ja.md)

Веб-интерфейс для [кодирующего агента pi](https://github.com/badlogic/pi-mono). В VSCode/VSCodium встраивается через расширение `pi-for-ide`.

- **`pi-web-for-ide`** (npm-пакет): улучшенный pi-web. В браузере работает как **Pi Web+**, при встраивании через `?embed=<host>` переключается в режим **pi for IDE**. CLI: `pi-web`.
- **`pi-for-ide`** (расширение VSCode): лёгкая оболочка, которая запускает или подключается к глобально установленному пакету.

Апстримы: [pi-web](https://github.com/agegr/pi-web) (agegr, сам веб-интерфейс), [pi-code](https://github.com/wangjinxin613/pi-code) (wangjinxin613, первоисточник IDE-интеграции).

Подробности см. в [README.md](./README.md) (англ.) или [README.zh-CN.md](./README.zh-CN.md) (кит.).
