# pi-code — Pi Web+ / pi for IDE

[English](./README.md) | [中文](./README.zh-CN.md) | [Русский](./README.ru.md)

[pi コーディングエージェント](https://github.com/badlogic/pi-mono) の Web インターフェース。VSCode/VSCodium には `pi-for-ide` 拡張機能として組み込めます。

- **`pi-web-for-ide`**（npm パッケージ）：強化版 pi-web。ブラウザでは **Pi Web+** として独立動作し、`?embed=<host>` で埋め込むと **pi for IDE** モードに切り替わります。CLI: `pi-web`。
- **`pi-for-ide`**（VSCode 拡張機能）：グローバルインストール済みのパッケージを起動・接続する軽量ホストシェル。

上流：[pi-web](https://github.com/agegr/pi-web)（agegr、Web UI 本体）、[pi-code](https://github.com/wangjinxin613/pi-code)（wangjinxin613、IDE 統合の起源）。
